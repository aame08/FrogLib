# FrogLib — платформа для книжного сообщества.

Дипломный проект. Цель — создание единого пространства для читателей, где можно управлять книжными списками, делиться мнениями и находить новые книги.

## Что умеет платформа.

### Для пользователей.

**Главная страница**

- Тематические блоки: «Книжные новинки», «Бестселлеры», «Популярные книги», «Популярные рецензии», «Популярные подборки»
- Для авторизованных — блок персональных рекомендаций с пояснением принципов работы системы

**Каталог книг**

- Поиск, фильтрация и сортировка
- Карточки книг с обложками
- Страница книги с разделами: информация, рецензии, подборки
- Полные библиографические данные и статистика (распределение оценок, добавления в списки)
- Оценка книги от 1 до 5 звёзд с возможностью изменения или удаления

**Рецензии**

- Написание отзыва с заголовком, оценкой и текстовым редактором
- Каталог всех рецензий с поиском и сортировкой
- Страница рецензии со статистикой (просмотры, оценки)
- Комментарии к рецензиям

**Подборки**

- Создание и редактирование подборок
- Добавление книг (в том числе сразу со страницы книги)
- Каталог подборок с поиском и сортировкой
- Страница подборки с описанием, списком книг, статистикой и комментариями

**Личный кабинет**

- Профиль с аватаром и датой регистрации
- Раздел «Книги» — персональная коллекция с фильтрацией, сортировкой и поиском
- Раздел «Комментарии» — все оставленные комментарии
- Раздел «Подборки» — свои и сохранённые подборки других авторов
- Раздел «Рецензии» — все написанные отзывы с сортировкой
- Раздел «Календарь» — учёт литературной активности по дням с цветовой индикацией статусов чтения

**Аутентификация**

- Регистрация и вход через модальные окна
- Сброс пароля
- JWT-токены

### Для модераторов

- Проверка рецензий и подборок перед публикацией
- Автоматическое выделение запрещённых слов
- Принятие, отклонение или отклонение с указанием причины и категории нарушения
- Модерация комментариев — подтверждение или удаление с причиной
- Управление пользователями — просмотр нарушений, блокировка и разблокировка
- Визуальная индикация проблемных аккаунтов (оранжевый — 5–9 нарушений, красный — 10+)

### Для администраторов

- Управление книгами: добавление через Google Books API, редактирование
- Управление авторами и категориями
- Управление подборками
- Управление сотрудниками (модераторы и администраторы)
- Фильтр запрещённых слов — добавление, удаление, поиск

## Рекомендательная система

Гибридный метод, комбинирующий два подхода для максимально точных рекомендаций.

### Как это работает

**Контентная фильтрация (60% итоговой оценки)**

- Анализ описания книги с помощью TF-IDF векторизации (с фильтрацией русских стоп-слов)
- Учёт категории книги как дополнительного признака
- Поиск похожих книг через косинусное сходство на основе любимых книг пользователя (вес взаимодействия ≥ 4)

**Коллаборативная фильтрация (40% итоговой оценки)**

- Построение матрицы пользователь-книга на основе:
  - Явных оценок (1–5 звёзд, с удвоенным весом)
  - Списков чтения: «Любимые» (вес 4), «Прочитано» (вес 3), «Хочу прочитать» (вес 2), «Не понравилось» (вес 1), «Отложено» (вес -1)
- Снижение размерности через TruncatedSVD (до 50 компонент)
- Предсказание оценок для книг, с которыми пользователь ещё не взаимодействовал

**Итоговая формула:**

> score = 0.6 × content_score + 0.4 × collab_score

### Поведение в особых случаях

- Если пользователь новый и взаимодействий нет — возвращаются самые популярные книги
- Если все подходящие книги уже просмотрены — также возвращается топ популярных
- Данные обновляются каждый час

### Технические детали

- Язык: Python 3.10
- Фреймворк: FastAPI 0.115
- Библиотеки: scikit-learn (TfidfVectorizer, TruncatedSVD, cosine_similarity), pandas, numpy, scipy, nltk
- База данных: MySQL (через pymysql)

## Технологии

- **Сервер**: C# 12, ASP.NET Core 8.0, JWT
- **Клиент**: JavaScript ES2024, Vue.js 3.5
- **Рекомендательный сервис**: Python 3.10, FastAPI 0.115
- **Внешние API**: Google Books API
